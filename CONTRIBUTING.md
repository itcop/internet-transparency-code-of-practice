# Contributing

Everything about how this is developed, what is settled, what is open, and how a
comment is handled is in [PROCESS.md](PROCESS.md).

The short version:

- **A specific change to the text** goes in an issue, or a pull request.
- **A question or an objection to the approach** goes in a
  [discussion](https://github.com/itcop/internet-transparency-code-of-practice/discussions).
- **Anything you would rather not say in public** goes to info@tcieg.org. A
  comment made by email is not published with a name attached to it.

**Commenting places you on no list.** There is no membership. Contributors whose
text is merged appear in the commit history, which is a consequence of using git
and is visible before anyone contributes. Nothing else is recorded anywhere.

Reuse terms for anything you contribute are in [LICENSE.md](LICENSE.md).
